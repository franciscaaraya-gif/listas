# **App Name**: CallConnect

## Core Features:

- Centered Image Display: Display a centered logo or illustration on the home screen.
- Button Navigation: Provide four navigation buttons: 'New Call', 'View Other Calls', 'View Volunteer', and 'Exit'.
- New Call Initiation: Enable users to initiate a new call from the home screen.
- Call History Viewing: Allow users to view a history of their other calls.
- Volunteer Details: Enable users to view details about the assigned volunteer.
- Application Exit: Provide a clean exit from the application.

## Style Guidelines:

- Primary color: Soft blue (#89CFF0), evokes trust and calm.
- Background color: Very light blue (#F0F8FF), almost white, provides a clean and calming backdrop.
- Accent color: Light green (#90EE90) to provide subtle and friendly call-to-actions.
- Font: 'PT Sans', a friendly and accessible sans-serif font, will be used throughout the app for headlines and body text. 
- Center the main image and arrange buttons in a clear, accessible layout.
- Use simple, clear icons for buttons to aid recognition.
- Subtle transitions on button presses to provide user feedback.
